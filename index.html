设计判断

1. 极简 3/5/9 单次消耗，杜绝通胀

为了让 C 端用户对积分价值有清晰的认知，将基础单次消耗降至极简的 3 积分/次。不搞百万级别的大数字通胀，整体体系更符合严谨的金融工具调性。

2. 四档价格阶梯，锁定长期 LTV

每个套餐提供「首月约3折 → 续费67-78折 → 单月原价 → 包年83折」四档价格。首月超低门槛（进阶¥9.9/高阶¥39.9/旗舰¥79.9）拉新转化，包年（¥199/¥699/¥1,288）付10月享12月锁定长期用户。

3. 限时体验季策略：先体验后转化

体验季注册即送 50,000 限时积分（约 16,667 次 T1 / 10,000 次 T2 / 5,556 次 T3），解锁全部 T1/T2/T3 工具与 Skill，让用户在 5/31 到期前充分体验深度功能的价值。到期后限时积分清零、T3 权限收回，依赖深度分析的用户自然转化为付费用户。通过「成为生态伙伴」任务（仅限机构/投顾团队）收集 B 端合作线索与高价值用户画像，同机构仅首人获积分奖励，支撑精准续费运营与 B 端拓展。

4. 什么是 QPS？为什么限制 QPS？

QPS (Queries Per Second) 是“每秒并发查询量”。目前的每日“1000次”是指总容量，而 QPS 是指速度。C 端虽然有几万次总容量，但每次只能“排队”查（如 1 QPS 就是一秒只能查 1 次）。而量化机构需要在一秒内同时查几百个数据，他们就必须去买 100 QPS 起步的 B 端昂贵接口。这就是我们保护商业底线的护城河。

5. 多平台接入：Key = 统一计费网关

且慢 MCP 支持 Cursor、Trae、阿里云百炼、Claude Desktop、Windsurf 等所有 MCP 客户端。所有平台上的鉴权和计费逻辑统一在且慢 Server 端完成——平台只是"哑管道"，不参与计费。用户在开放平台注册获取 API Key，将 Key 配置到任意客户端即可使用，积分余额跨平台通用。

6. API 错误文案 = 第三方平台上的付费入口

由于 Cursor/Trae/百炼等第三方平台不提供自定义付费弹窗，当用户积分不足或权限不匹配时，Server 返回的错误文案就是在所有平台上唯一的付费转化入口。文案必须包含：① 当前状态说明 ② 恢复/升级路径 ③ 且慢控制台链接。详见下方"API 错误响应预览"。

Pre-Mortem 风险预案

假设上线 14 天后失败，逆向推演可能原因。

🐯 Tiger：免费层过于充裕

免费满勤 7,400 vs 进阶版 10,000（差距 26%），转化率可能 < 2%。缓解：灰度 A/B 测积分量；已下调至 200/天（7,400/月），继续监控转化率。

🐯 Tiger：积分系统复杂度高

三类积分 + 过期规则 + 优先级，用户理解成本高。缓解：新手引导必须覆盖积分体系；积分不足弹窗需清晰解释。

🐯 Tiger：邀请系统薅羊毛

批量注册小号刷邀请积分（每次 1000×2）。缓解：每人每月上限 5 人（5,000 积分封顶） + 设备指纹 + IP 限制 + 被邀请人须实名认证 + 首周人工巡检。

🐰 Rabbit：生态伙伴机构刷积分

同一机构多名员工各自提交表单，各得 5,000 积分。已缓解：该任务仅限机构/投顾团队申请（个人用户不可见），所属机构为必填字段，后端标准化机构名去重，同一 org_name_normalized 仅首位提交者获积分，后续同事信息入库但不发放。

🐯 Tiger：跨平台错误提示体验差异

且慢 MCP 运行在 Cursor/Trae/百炼等多平台，各平台展示错误文案的样式不同（Markdown 支持度、链接可点击性），可能导致付费引导链接不可用。缓解：错误文案同时包含完整 URL 文本；上线前在 Top 3 平台逐一测试全部 6 种错误场景。

🐘 Elephant：C 端投研付费意愿存疑

个人投资者长期习惯"免费看数据"，¥20-50/月的付费接受度未验证。建议：上线前做 200 人 WTP 问卷。

🐘 Elephant：B2B 平台合作模式未定义

当百炼/Trae 提出将且慢 MCP 作为平台内置能力时，商务合作模式（分成/买断/订阅）、平台级 Key 技术方案、用户归属等关键问题尚无预案。建议：V1.0 上线后 1 个月内起草平台级合作框架草案。

⚖️ 合规致命缺口（评审 P0 补充）

金融支付产品完全缺失用户服务协议、数据安全架构、投资建议免责声明——法务一票否决风险。已补充至 PRD §12.5：用户协议 + 隐私政策 + 免责声明三件套，V1.0 发布前必须通过法务审核。Go/No-Go 新增 G7（协议审核）和 G8（免责嵌入）两道门。

开放平台 Key 接入模型

用户在开放平台注册获取 API Key，配置到 Cursor / Claude 等 MCP 客户端即可一键使用工具和 Skill。

1. Key = 身份 + 层级 + 计费

API Key 绑定用户订阅层级，同时承载工具权限（基础查询T1/智能分析T2/深度研究T3）、Skill 权限（按层级解锁）和积分余额。无需额外登录或鉴权。

2. Skill 不额外收费的设计逻辑

Skill 底层调用的每个 MCP 工具已正常扣分（如 fund-analyst 一次约消耗 40-80 积分）。若 Skill 本身再收一层"编排费"，用户会绕过 Skill 手动调工具省钱——这反而削弱平台的核心竞争壁垒。

3. Skill 是升级的核心驱动力

体验版仅 3 个基础 Skill → 进阶版解锁基金分析 Skill → 高阶版解锁组合诊断和财务规划。相比"多一点积分"，"多一套能力"对用户的价值感知更强烈。
